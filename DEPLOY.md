# Deploying

The Ontwerpboek is live at **https://moose-puce.vercel.app**. The Vercel project `moose` deploys the
`main` branch to production automatically on every push. No build step: Vercel serves the files as-is
(framework preset "Other").

Preview deployments of other branches sit behind Vercel's login wall (Deployment Protection), so
always share the production link with clients.

The previous Restaurant Moose site is preserved on the `restaurant-moose` branch.
